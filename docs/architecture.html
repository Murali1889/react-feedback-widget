Submit pipeline

Capture

Reporter presses Alt+A or Alt+Q. The widget snapshots the clicked element + React fiber state, computes selector path, walks build info & active flags. Eager compression kicks off the moment a screenshot lands.

Compress Worker

PNG → WebP @ q=0.85 via OffscreenCanvas in a Web Worker. Typical screenshot 1.0 MB → 20 KB (98%). Main thread never blocks. encodedOn: 'worker' in the payload metadata.

Build AI ticket

Assembles Markdown + JSON: Where (file:line), Repro (last 30 actions), Logs, Environment (Vitals, network, locale, memory), State (fiber), Evidence, Annotations.

Dispatch Parallel

dispatchToDestinations() fans out to every adapter in parallel. Per-destination status: { ok, id, url, durationMs }. One failure never blocks another.

Surface

Submission toast renders status chips per destination: ✓ local · ✓ github · ⚠ supabase. Failed-fanout toasts stay 6s instead of 3s.

Upload tiers — picked automatically

Tier 1 json

Inline base64 in JSON. No binary handling on the server.

30.5 KB / destination
When: no binary, or local() only.

Tier 2 multipart

Auto-switch when payload has binary. Separate multipart part — no base64 inflation.

24.3 KB / destination
When: default for binary — works everywhere.

Tier 3 signed-URL ⭐

Browser PUTs directly to S3 / R2 / Supabase Storage. App server never sees the bytes.

8.6 KB / destination
When: production volume. Saves bandwidth + parallelizes upload with metadata POST.

Object storage providers (for signed-URL tier)

AWS S3 / R2 / MinIO

AWS Signature V4 over native crypto. R2 uses region: 'auto' + the R2 endpoint URL. Works for B2, Wasabi, DO Spaces.

Supabase Storage

REST /storage/v1/object/upload/sign/.... 2-hour upload validity. publicBaseUrl for CDN reads.

Custom signer

Pass a function to provider. Receives { name, mimeType, size, key, config }, returns { url, headers, finalUrl, expiresAt }.

Security boundary

No browser-side adapter ever holds a production credential.

  • Refused at construction — adapter constructors throw FeedbackCredentialLeakError if they see a known-private-key shape (GitHub PAT, Linear key, Atlassian token, AWS access key, Stripe secret, Slack token, Notion token, Supabase service-role JWT, …).
  • Server-side proxied by default — every server-proxied adapter wraps with withSecureDefaults({ authorize }) which enforces origin allow-list, CSRF check, rate limit, your authorize callback, payload validation, and defense-in-depth redaction.
  • Public-token adapters are explicitly named *Public with the RLS / lockdown SQL in the doc. Default is server-proxied; public is opt-in.
  • Storage paths server-scoped — signed-URL handler derives the path from authContext.projectId/userId so a user with a valid session can only write into their own scope.
  • Short URL expiry — 5-minute default on AWS Sig V4. URLs are UNSIGNED-PAYLOAD so they accept any-size PUT up to the bucket cap.
  • Hosted cloud SKU uses Sentry-style write-only ingest tokens — identity, not auth. Worst case if token leaks: garbage feedback to your project from approved origins. No data exfiltration.
